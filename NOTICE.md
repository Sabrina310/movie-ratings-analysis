This repository packages a **CPSC 368 Group 1** course project. The surviving reports identify the group but do not establish individual authors or their contributions. Add verified contributor names and roles when available.

IMDb, Rotten Tomatoes and Oscar data originate from the sources recorded in [docs/DATA.md](docs/DATA.md). Included CSV files are saved cleaned project snapshots. No project-wide open-source license has been selected on behalf of the original contributors. Public display of a repository should not be mistaken for a grant of unrestricted reuse rights. Choose an appropriate code license only with the relevant contributors' authorization, and keep third-party data terms separate.

Historical PDFs are preserved unchanged. New documentation, reproducibility scripts and tests were prepared with AI assistance during portfolio reorganization. See [the reorganization record](docs/REORGANIZATION.md).
